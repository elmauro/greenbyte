# GreenByte Infrastructure

AWS infrastructure organized by capability, aligned with existing serverless projects.

## Structure

```text
infrastructure/
├─ cognito/
├─ dynamodb/
├─ parameters/
├─ secrets/
├─ postgresdb/
├─ proxydb/
├─ ses/
├─ web/
└─ scripts/
```

Each capability keeps its own state, variables and runbook when applicable.
